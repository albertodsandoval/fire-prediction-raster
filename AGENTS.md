# Agent Instructions

This repository keeps a durable session log in [CONVERSATION_LOG.md](C:/Users/ads80408/Development/fire-prediction-raster/CONVERSATION_LOG.md).

Update that file when:
- A user request results in code or file changes.
- A user instruction creates a persistent workflow rule for future sessions.
- A conversation establishes a concrete technical reason for why an implementation was chosen or avoided.

Do not log:
- Routine Q&A with no repository impact.
- Temporary diagnostics that did not change code or future behavior.
- Full transcripts, verbose command history, or low-signal summaries.

Logging style:
- Append entries by date.
- Summarize the user request, the meaningful decision, and the resulting repo change or constraint.
- Keep entries concise and readable in a quick handoff scan.
